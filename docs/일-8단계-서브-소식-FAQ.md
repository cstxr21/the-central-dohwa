## 분양소식 `/news` (모티프 `news`)

- **TITLE** `{현장명} 분양소식 | 공급정보·부동산 동향` · **DESC**(≤80) `{현장명} 분양소식. 최신 공급정보, 입지분석, 부동산 시장동향과 언론사 보도자료를 한눈에 확인하세요.`
- **H1** `{현장명} 분양소식` · **H2** 최신 공급정보(인트로) · 발행 글 · {현장명} 관련 보도자료(언론사별).
- **색인 페이지**: 최신 분양정보 인트로 → **발행 글 카드**(카테고리·날짜·제목·발췌, 매거진 2단) → **언론 보도자료 아카이브**(언론사별 H3 + 외부 원문 링크 `target=_blank rel=noopener`) → 운영 방향/About.
- **발행 글 상세 `/news/[slug]`**: 에디토리얼 헤더(breadcrumb·카테고리·날짜·H1·리드) → H2 본문 섹션 → 출처 주석 → 관련 페이지 링크. **`NewsArticle` JSON-LD**(headline·datePublished·dateModified·author·publisher·mainEntityOfPage).
- 데이터 `lib/news.ts`(`POSTS` 발행 글 + `PRESS` 보도 아카이브), `generateStaticParams`로 글 추가 시 자동 라우트, sitemap에 글 포함. **RSS 피드 라우트(`app/rss.xml`)도 8단계에서 생성**(POSTS 기반, 10단계 발행 시 자동 반영).
- ⚠️ **샘플·더미 글 발행 금지**: 8단계에서는 `POSTS`를 **빈 배열 `[]`**로 둔다(샘플·예시·더미 글 **0편**). `/news` 색인·카드 레이아웃·`NewsArticle` 템플릿·RSS·JSON-LD 구조는 빈 `POSTS`로 검증을 통과한다(`[G8-NEWS]`가 **색인·rss 구조만** 강제). 실제 글은 **[10단계] 시드 3편**으로 첫 배포 전에 채운다. 여기서 샘플을 넣으면 10단계 시드와 **합쳐져 과발행**(예: 샘플 2 + 시드 3 = 5편)된다.
- 보도 인용은 **출처(언론사) 명시** · 미확정 정보는 "입주자모집공고 기준 추후 안내".
- **About** `{현장명} 분양소식 한눈에 보기` 공급정보·입지분석·시장동향·보도자료 지속 업데이트 / 분양가·일정 추후.
- **권장 텍스트 수·이미지**: 색인 인트로 2~3문장 + About 600~1,200자. 발행 글 상세(`/news/[slug]`)는 H2 2~3개·본문 800자+. **발행 글 카드 썸네일 이미지 활용**(alt=제목+매체, width/height 명시). 보도 아카이브 항목은 매체·날짜·헤드라인·1줄 요약(near-duplicate 금지).
- **운영 목표** 최소 30편 이상 누적 → 실제 글 발행은 **10단계** 반복.

## FAQ `/faq` (모티프 `qa`)

- **TITLE** `{현장명} FAQ | 자주 묻는 질문` · **DESC**(≤80) `{현장명} 자주 묻는 질문. 분양, 방문예약, 계약·입주, 주차·이용 등 궁금한 점을 확인하세요.`
- **H1** `{현장명} FAQ` · **H2**(카테고리별 아코디언 + FAQPage JSON-LD) 분양 관련 질문 · 방문예약 안내 · 계약 및 입주 안내 · 주차 및 이용 안내 · 기타 문의사항.
- UI: **카테고리별(H2) 아코디언**(`<details>`/`<summary>` — JS 없이 콘텐츠가 정적 HTML 노출 → 네이버 Yeti·AI 추출 가능). `+`→`×` 회전 표시.
- **사이트 FAQ 허브 — `FAQPage` JSON-LD는 이 페이지에만**(서브페이지 FAQ 섹션·스키마 복제 금지 = 중복 방지). `dateModified` 포함.
- 분양가·일정 등 미확정 답변은 임의 수치 금지("입주자모집공고 기준 추후 안내"). 인접·동일부지 내 별개 단지가 있으면 본 단지와 구분 명시.
- **권장 텍스트 수·구조(H2/H3 최대 활용)**: 카테고리(H2) 4~6개 + 질문 총 12개+(페이지 고유 질문, 같은 Q 여러 페이지 복제 0), 답변 각 1~3문장 검증 fact. 분량은 정보 밀도 우선(개수 맞추기용 억지 답변=어뷰징). 답이 "추후 안내"뿐인 질문으로 개수 채우지 말 것.
- **About** `{현장명} 자주 묻는 질문 한눈에 보기` 분양·방문예약·계약/입주·주차/이용 / 미정은 입주자모집공고 기준 추후, 추가 문의 {전화} 1~2문단(400~800자).
