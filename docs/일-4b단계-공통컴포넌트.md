> 🔒 **완료·배포 게이트 (모든 단계 md 공통 — 복붙 필수)**: 이 단계를 "완료"라고 말하기 전에, 이 문서의 `## 완료조건 (기계 판정)` 항목을 **마스터 `scripts/verify.mjs`로 실행**(`npm run verify`)해 **전부 PASS(GREEN)** 임을 출력으로 증명한다. 하나라도 FAIL·미구현·미측정·증거없음이면 **미완료** — "했다"고 말하지 말 것. auto 항목은 스크립트가 빌드결과·public·src를 읽어 검사, manual 항목은 `reports/manual-evidence.json`에 증거(수치·경로·요약)를 채워야 PASS. 마스터 verify 스크립트 원본·사용법은 **[11단계](일-11단계-배포점검.md) §마스터 검증 스크립트**에 있다. 신규 현장은 docs 프로세스 md 전체를 복붙 → 그 코드블록을 `scripts/verify.mjs`로 저장 → `content.ts`/`site.ts`만 그 현장 값으로 채우면 게이트가 자동으로 그 현장 기준 검사한다(라우트·슬러그 자동 감지). (현장 산출물 `이미지-배치표.md`는 복붙 대상 아님.)

# 4b단계 — 공통 컴포넌트

> **작업 순서 4b/11** · 전제: 2단계(토큰)·3단계(전역 규칙)·4a단계(레이아웃) · 자기완결(UI §3.2~3.7 원문 포함)
> **목적**: 메인·서브가 재사용하는 공통 컴포넌트를 만든다.
> **산출물**: `SectionHeading`·`LineSpec`·`MagBlock`·버튼·폼(`InterestForm`)·`/privacy`(개인정보처리방침)·카드/이미지 규칙
> **배포 점검(11단계)**: 폼 컴포넌트 실동작과 미사용 공통 컴포넌트 정리는 배포 직전 **[11단계](일-11단계-배포점검.md)**가 점검한다(폼 미작동·동의/처리방침 누락 = blocker).

## 1. 버튼 (UI §3.2)

| 변형 | 스타일 |
|---|---|
| Primary | 1px 보더(`border-current`/ink) · transparent bg · hover 채워짐/opacity-60 |
| Solid | `bg-ink text-ivory`(모바일 CTA 통바·폼 제출, 풀폭 가능) |
| Text only | underline offset 4px · hover bronze |
| **Circle(어텐션)** | 히어로 단일 핵심 전환 **원형**(`rounded-full` ~128~160px) · 2~3줄 라벨(한글 주+영문 장식) · `motion-safe:animate-ping`+`animate-pulse` 글로우 + hover `scale-105` |

- radius 0(원형 제외), padding `px-5 py-2.5`~`py-4`(터치 48px). 라벨 한글 주+영문/숫자 보조, 자간 0.05em 이하. 브론즈 버튼 텍스트 14px 미만 금지.
- 이미지 위 원형 CTA = 따뜻한 야경엔 샴페인/웜톤 원+잉크 글자(흰색=떠 보임, 다크=묻힘), 글로우 브론즈, `motion-safe` 한정.

## 2. 폼 (UI §3.3)

- 입력 = 언더라인 only(`border-b border-line`) 또는 테두리 박스(`border border-line px-4 py-3`) 중 톤에 맞게(폼카드 흰 배경이면 테두리 박스가 또렷).
- **라벨 필드 위 한글 16px 고정**(플레이스홀더 대체 금지 — 플레이스홀더는 예시 입력값만). 입력 17px+ ink.
- 포커스: 보더 색 브론즈 + 언더라인/보더 2px(색만 의존 X).
- **에러 한글 우선**(`연락처를 올바르게 입력해 주세요`, `text-ink`+굵기 500). 색은 ink 계열, 아이콘/굵기로 구분.
- 필드 간 세로 간격 `gap-7`+. 제출 버튼 풀폭 `bg-ink`.
- **개인정보 동의**: 수집항목·이용목적·보유기간 **테두리 박스로 분리** + 동의 체크박스 + 처리방침(`/privacy`) 링크(개인정보보호법 필수).
- **관심고객등록 폼 정본 필드**: `성함`·`연락처`·`연락 가능한 시간대`(라디오: 오전9–12/오후12–15/오후15–18/저녁18 이후/아무때나)·동의 — 별도 페이지 없이 메인 하단 + 모델하우스.
- **연락처 자동 하이픈(가독성 필수)**: 입력 즉시 숫자만 추출해 `-`를 자동 삽입한다(`010-1234-5678`). `onChange`에서 `formatPhone()` 적용 — 02(서울) 2자리 국번, 그 외 3자리 국번, 11자리=`3-4-4`/10자리=`3-3-4`. `inputMode="numeric"`(모바일 숫자패드), `maxLength={13}`. 검증 정규식(`/^0\d{1,2}[-\s]?\d{3,4}[-\s]?\d{4}$/`)은 하이픈 포함 값을 그대로 통과.
- **선택 헤더 prop**: `eyebrow`(영문 라벨)·`title`·`note`로 폼 상단 제목/안내 표시(예: `Reservation Form` / `방문예약 신청` / `담당자가 확인 후 연락드려…`). 메인·모델하우스에서 재사용(좌 정보 ↔ 우 폼 영문 eyebrow 대칭).

## 3. 섹션 헤딩 (`SectionHeading`, UI §3.4)

- 브론즈 번호(`font-accent` italic 15px, tracking-widest) + `font-serif` bold 헤드(26px → `sm:34px`, `text-ink`).
- `no` prop 선택 — 번호 없는 헤딩도 허용.

## 4. 라인 디스플레이 (`LineSpec`, UI §3.5)

- `border-t/b border-line`, 각 행 `py-5`. dt = 브론즈 번호(15px) + `text-muted` 라벨(15px), dd = `text-ink` 17~18px **medium**.
- 사업개요·공급정보 등 "라벨/값" 표는 모두 이 컴포넌트로 통일.

## 5. 카드 / 이미지 (UI §3.6)

- 카드 최소화. 사용 시 transparent bg · `border-line` 1px · radius 0 · hover 시 보더 ink로 진해짐(transform 없음). 제목 18px+ / 본문 16px+.
- hover 미세 scale(1.02)+ease-out. 이미지는 `<Link>`로 감싸 **클릭 가능 + 호버 줌**(`group-hover:scale-[1.02]`).
- **이미지 잘림 방지(중요)**: 비율 제각각(가로 조감~2.0, 세로 외관~0.7, 정사각 지도). 고정 `aspect`(예 4/3)+`object-cover`로 묶으면 전부 잘림 → 둘 중 하나:
  - 컨테이너 비율을 **각 이미지 실제 비율**(`style={{aspectRatio:w/h}}`)에 맞춤 → `object-cover`여도 잘림 0.
  - 튀는 컷(세로 외관)은 같은 톤 가로 이미지로 교체.
  - `next/image`는 width/height(또는 비율) 명시(CLS 방지). webp 우선.
- **캡션은 이미지 아래 단색 배경에 16px+.**

## 6. 섹션 매거진 블록 (`MagBlock`, UI §3.7)

- 메인·서브 "이미지+내용" 섹션 정본. props `{ no, en, title, image, alt, ratio, href, linkLabel, reverse, bg, children }`.
- 2단 그리드(`lg:grid-cols-2 items-center`), `reverse`로 이미지 좌/우 교차. 내용 = eyebrow(번호+영문) → H2(serif) → `children`(fact 문단/리스트/`LineSpec`) → 자연어 링크.
- 이미지 컨테이너 `style={{aspectRatio:ratio}}`(=실제 w/h). ⚠️ **이미지엔 링크·hover 줌 없음 — 이동은 `linkLabel`로만**([5단계 §섹션 매거진 블록] 정본). `<Link>` 래핑·`group-hover:scale` 금지(과거 사양 폐기).
- `bg`는 섹션 교차색(`bg-surface`/`bg-background`)을 호출부에서 번갈아 주입.
- ⚠️ 같은 섹션을 "상단 카드 네비 + 하단 텍스트"로 **이중 배치 금지** — MagBlock 하나로 통합(중복 방지).

## 7. 위치/주소 안내 (길찾기 버튼 미사용)

- ⚠️ **`MapLinks`(네이버·카카오·구글 길찾기 3버튼) 미사용** — 외부 지도앱으로의 이탈은 전환(방문예약 폼)에서 벗어나게 하고 SEO·AI 유입 기여가 0이라 **전 페이지에서 제외**.
- 위치는 **주소·전화 텍스트 + 위치안내 표 + 입지 지도/안내도 이미지**로 안내하고, 주소·전화는 모델하우스 `LocalBusiness`/`RealEstateAgent` **JSON-LD**([7단계](일-7단계-서브-분양-모델하우스.md))로 구조화 노출(검색·AI가 읽는 건 길찾기 버튼이 아니라 이 구조화 데이터).

## 8. 개인정보처리방침 (`/privacy`)

- 관심고객등록 폼의 **개인정보 동의 대상 페이지**(§2 폼 동의 박스 → `/privacy` 링크). 라우트 골격은 4a, **본문은 여기 규정**(빈 골격 방치 금지 — 개인정보보호법상 폼 운영 요건).
- **개인 운영이면 간소화** — 표/리스트로 핵심 항목만: 수집 항목(성함·연락처·연락 가능 시간대) / 이용 목적(분양 상담·방문예약 안내) / 보유 기간(분양 종료·동의 철회 시 파기) / 제3자 제공(미제공, 법령 예외) / 정보주체 권리(열람·정정·삭제·동의 철회) / 동의 거부(가능, 거부 시 안내 제한) / 문의처(대표문의 `{전화}`) / **시행일(`LEGAL.lastUpdated`)**.
- **기업 운영이면 추가**: 처리 위탁·파기 절차·안전성 확보 조치·개인정보 보호책임자(성명·연락처). ⚠️ 보호책임자 등 **미확보 정보는 창작 금지**(확보 시 추가).

- [ ] 버튼(Primary/Solid/Text/Circle) · 폼(라벨 고정·한글 에러·동의 박스·풀폭 제출 · 선택 eyebrow/title/note 헤더)
- [ ] **`/privacy` 본문 작성**(수집·목적·기간·제3자·권리·동의거부·문의·시행일) — 폼 동의 박스에서 링크 연결, 빈 골격 0(개인정보보호법)
- [ ] **길찾기 버튼(`MapLinks`) 미사용** — 위치는 주소·전화 텍스트 + 입지/위치 안내 이미지·표 + `LocalBusiness` JSON-LD(7단계)로만, 외부 지도앱 링크 0
- [ ] SectionHeading · LineSpec(값 17~18px ink medium) · MagBlock(이중 배치 0)
- [ ] 이미지 잘림 방지(컨테이너 비율=실제 비율 또는 가로 교체), 캡션 이미지 아래 16px+
- [ ] 관심고객등록 폼 정본 필드(성함·연락처·연락가능시간대 라디오·개인정보 동의) 일치 + 개인정보처리방침(/privacy) 링크 연결
