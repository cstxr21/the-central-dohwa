# 사이트 완전 추출 프롬프트 (범용 — 수집/추출)

**목적**: 임의의 대상 사이트의 모든 페이지 텍스트 + 이미지/영상/문서 + 이미지 속 텍스트를 누락 0으로 추출한다. (외부자료 사실 대조·보강은 1b)
**사용법**: 아래 코드블록을 AI에 그대로 전달. `< >`로 표시된 자리표시자만 대상에 맞게 교체.

## 프롬프트 (복사해서 사용)

```
[대상]
- 사이트: <TARGET_URL>
- 저장: <SAVE_PATH>  (있으면 기존 내용 삭제 후 새로 저장. resume 켜면 manifest 기준 완료분 보존)
- 작업: 전 페이지 텍스트 + 이미지/영상/문서 + 이미지 속 텍스트 누락 0 추출. (사실 대조·보강은 다음 1b단계)
- 도메인 컨텍스트(선택): <DOMAIN_NOTE> (예: 분양/커머스/기업소개/뉴스 — 비우면 일반 웹사이트로 처리)

[구현 — 이 프로젝트엔 추출기가 아직 없다고 가정]
- 이 스펙(⓪~④)을 그대로 구현하는 스크립트를 직접 작성·저장·실행한다: 기본 `scripts/extract-site.mjs` (Node ESM + Playwright/Chromium).
- 의존성 없으면 설치(`npm i -D playwright` → `npx playwright install chromium`). 비전 LLM/Tesseract는 [전제조건] 참고.
- ①~③(크롤·다운로드·SVG 파싱)은 스크립트로 자동화, ④ 래스터 OCR은 산출물(ocr.json·manifest)을 입력으로 비전 LLM으로 채운다.
- ⑤ 사실대조·⑥ 보강은 이 단계가 아니라 [1b단계]에서 수행한다(여기선 원자료만 누락 0으로 확보).
- 실행 후 [완료 조건]을 report.txt로 자가검증하고, 미달 항목은 재실행/수정.

[전제조건 — 결손 시 멈추지 말고 fallback, report에 명시]
- Playwright + Chromium (없으면 설치).
- 비전 LLM (④ 주력 판독, 필수).
- Tesseract (④ 교차검증, 선택. 없으면 LLM 단독. 대상 언어팩 설치).
- 외부 웹 접근(공식 문서 다운로드 등) 불가·미공개 항목은 "미확정" 표시 후 계속.
- 인증/로그인 영역은 자격증명 없으면 진입하지 않고 URL만 기록.

[임계값]
- 로드: networkidle 60s, 초과 시 domcontentloaded + 3s.
- 스크롤 끝 후 1.5s. 인터랙션 클릭: 셀렉터당 ≤12개, 간격 0.25s.
- BFS ≤400페이지, 동일 origin만(필요 시 상향).
- 쿼리 조합 저장: HTTP 200 AND 본문 ≥30자.
- OCR 대상: 한 변 ≥200px AND 글자 포함, 콘텐츠 해시 1회(URL 아님).
- 다운로드 타임아웃: 이미지 60s / 영상·PDF·문서 180s. 실패는 기록 후 계속.

⓪ 실행 설정 (효율 — 단일 브라우저 컨텍스트 재사용)
- 동시성: 페이지 방문 워커 풀 N=4(동일 호스트 예의, 429/503 시 자동 감속). 다운로드는 별도 큐.
- 리소스 차단(route): 트래커/광고/분석(ga·gtag·facebook·doubleclick 등)·웹폰트는 abort로 로드 생략(콘텐츠 자산은 차단 금지). 차단 목록은 report에 기록.
- 네트워크 응답 가로채기를 페이지 시작 전 등록: XHR/fetch JSON, image/*, video/*, application/pdf, 문서를 전부 후킹(②·③에서 소비).
- 재실행(resume): manifest.json에 (url|file)→contentHash·status 기록. 동일 해시·status=ok는 재방문/재다운로드/재OCR 건너뜀(`--force`로 무시). 부분 실패만 재시도.
- dedup: 페이지는 정규화 본문 해시, 이미지/문서는 바이트 해시. 같은 해시 다른 URL은 첫 1건만 저장하고 alias 목록에 URL 기록.
- canonical/redirect: <link rel=canonical>·최종 redirect URL 기록, 중복 라우트는 alias로 병합(원본 URL 목록 보존).

① 페이지 발견
- robots.txt·sitemap.xml로 URL 확보.
- <a href> + onclick·data-href·data-url·data-link·data-target·버튼·JS location 문자열 파싱해 모든 내부 라우트 수집.
- 쿼리/파라미터 라우트 전수: 동일 경로의 파라미터 조합(탭·필터·페이지네이션·정렬·카테고리·옵션)을 발견.
  탭·드롭다운·필터 클릭으로 조합 발견, 안 되면 DOM·스크립트·URL 패턴에서 값을 뽑아 조합 생성.
- 내부 링크 BFS 재귀. 쿼리 다르면 별도 폴더(쿼리값 포함, 덮어쓰기 금지).

② 페이지별 텍스트 — PC(1440) 기본, 모바일(390)은 분기 시에만
- PC 먼저 방문. 모바일은 **항상 2회 돌리지 말 것**: ⓪에서 모바일 분리 자산(`_m`·다른 호스트)·다른 라우트·반응형 미디어쿼리로 콘텐츠가 달라지는 정황이 있을 때만 추가. 분기 없으면 PC 단일(report에 사유).
- ★**API 우선**: SPA·동적 목록은 렌더 DOM보다 ⓪에서 후킹한 XHR/fetch JSON이 정본. 응답 원본을 api/ 에 저장하고 텍스트 추출 1차 출처로 사용 → 깨지기 쉬운 탭 클릭 루프 의존도↓.
- 로드 → 끝까지 스크롤 → 인터랙션 전부 실행: 탭/스와이퍼/캐러셀/슬라이드 끝까지 클릭, 아코디언·더보기·팝업·모달 열기, 메뉴 토글, 무한스크롤 끝까지. (API로 이미 확보된 콘텐츠는 보강용으로만)
- 탭/슬라이드 전환마다 그 상태 innerText를 매번 저장(상태별 분리, 직전 상태와 동일 해시면 생략).
- 저장: page.html, innerText, meta·OG·헤딩(h1~h4), JSON-LD, 속성 텍스트(alt·title·aria-label·label·placeholder), api/*.json.

③ 이미지·영상·문서 다운로드
- DOM(img src/srcset/currentSrc, picture source, CSS background-image, SVG image href/xlink:href, video poster)
  ∪ 네트워크 응답(image/* · video/* · application/pdf · 기타 첨부 문서, 트래커 도메인 제외).
- 원본 URL 다운로드(썸네일·data:·디렉터리 URL 제외). video src/source.
- ★**이미지·영상은 대상 사이트와 동일 출처(same-origin)만 다운로드.** 외부 호스팅 이미지/영상은 **URL만 기록하고 받지 않는다**(manifest.externalAssets). 이유: 분양 사이트의 "언론보도/홍보센터" 상세는 외부 언론사 기사 HTML을 그대로 임베드해 **언론사 사진·네이티브 광고(다이어트·클릭베이트 등) 이미지가 수백 장 딸려 들어온다.** 이를 받으면 (1) 본 분양 CG가 아닌 쓰레기가 images/에 섞여 ④ OCR 비용·오염 폭증, (2) 1b 사실대조가 광고/타사 이미지를 분양 fact로 오인. 외부 기사의 **본문 텍스트는 pages/에 저장되므로 충분**하다(언론사 원본 사진은 불필요).
- ★단 **문서(PDF·공고문·약관·카탈로그 등)는 외부 호스팅도 다운로드**한다 — 공식 1차 문서는 외부 CDN에 있을 수 있고 1b 정본이 되기 때문(이미지/영상 규칙의 예외).
- ★PDF·첨부문서는 content-type만 의존하면 놓친다 — **다운로드 버튼·data-href·onclick·JS 트리거 뒤 파일**은 href/스크립트에서 URL을 뽑거나 클릭→다운로드를 가로채 **직접 fetch**. 1차 출처가 되는 공식 문서(공고문·약관·카탈로그·스펙시트 등)는 반드시 확보 시도 — **이 PDF가 1b 사실대조의 정본**이 된다.
- 쓰기 직전 폴더 보장(mkdir recursive).

④ 이미지 속 텍스트
- images/ 대상. **콘텐츠 해시 1회**(같은 이미지 다른 URL 재OCR 금지) + 트리아지(글자 포함 이미지만 — 엣지/엔트로피·텍스트 검출로 사진·배경 제외해 비전 호출 절감).
- ★**분양 CG 인포그래픽 패널은 전수 OCR(트리아지 제외 금지)** — 분양 원본은 콘텐츠가 이미지에 임베드돼(HTML text는 면책뿐) **세로 긴 CG 패널(단지설계·조경·커뮤니티·프리미엄·입지안내도 등 시설명·스펙·수치 박힘)이 정보의 핵심**이다. 사진으로 오분류해 트리아지에서 빼면 **정보 제약의 직접 원인**이 됨 → 텍스트 검출되면 무조건 OCR 대상(아래 고밀도 규칙으로 크롭 재판독).
- SVG: <text> 직접 파싱. ★단 **SVG가 아웃라인(글자를 패스로 변환, `<text>` 0개)**이면 파싱 불가 → 래스터처럼 비전 OCR 대상으로 돌린다.
- 래스터: 비전 LLM 전사(주력). ★**문맥 grounding**: 같은 페이지의 innerText·헤딩·alt·고유명사(브랜드/지명/제품명)를 프롬프트에 동봉해 환각·오탈자↓. 출력은 구조화 JSON(자유서술 금지) — {text, tables[], numbers[], confidence}.
- ★**고밀도 표·도면(가격표·스펙 리스트·치수·일정표·비교표)은 요약 금지.** 기본 해상도 1패스로 안 읽히면 **영역을 크롭/확대해 셀 단위로 전사**(필요시 분할). 핵심 수치(가격·수치·치수·일정)는 단일 패스 요약으로 끝내지 않는다.
- 교차검증: Tesseract 있으면 대조해 불일치만 표시. **없어서 생략하면 report에 "교차검증 미실행" 명시(묵시적 생략 금지).** 수치 표는 합산검산 등 자가검증 권장.
- 저장: ocr.json. 핵심 수치는 검수 대상 + 신뢰도 낮으면 `recheck:true`.

[출력 구조]
<SAVE_PATH>/
├─ pages/<slug>/   page.html, text.txt(+ text.<상태키>.txt), attrs.txt, meta.json, api/*.json
├─ images/  videos/  docs/   (파일명 = 콘텐츠해시.확장자, dedup)
├─ ocr.json        [{file, hash, svg, llm:{text,tables,numbers,confidence}, crosscheck, mismatch}]
├─ manifest.json   {pages[], images[], videos[], docs[], aliases[], hashes{}, status{}}  ← resume/dedup 인덱스
└─ report.txt
(factcheck.json·enriched.json은 1b 산출물)

[완료 조건 — report.txt에 보고]
① 미방문 URL 0건.
② 빈 텍스트 페이지 0건(있으면 사유). 탭 페이지는 상태별 text 존재.
③ 다운로드 실패 0 목표, 실패분 상태코드 기록. 공식 문서(공고문 등) 확보 여부 명시.
+ 공식 1차 문서 PDF(공고문·약관·카탈로그 등) 확보 시도 결과를 확보/미확보로 명시(미확보 시 사유) — 1b 정본 인계 가능 여부 기록 (0건이면 사유 필수).
④ 글자 포함 이미지 100% 텍스트 산출(**분양 CG 인포그래픽 패널 포함 — 트리아지 제외 0**). 고밀도 표·패널은 크롭 재판독으로 셀 단위 전사(요약 금지). 교차검증 실행/미실행 명시. 불일치·recheck 목록.
+ DOM vs 네트워크 이미지 수 비교, 쿼리/파라미터 조합 목록, 외부 iframe(cross-origin 수집불가) URL 목록.
+ **외부 호스팅 이미지/영상**(언론사 임베드 기사·광고 등): 다운로드하지 않고 URL만 기록한 건수 명시. images/ 안에 외부 출처 자산이 0건이어야 함(섞였으면 동일 출처 필터 누락 = 오염).
+ 효율 지표: 차단 리소스 종류·건수, dedup으로 생략한 페이지/이미지 수, resume로 건너뛴 작업 수, 모바일 2뷰포트 실행 여부와 사유, API로 확보(클릭 우회)한 콘텐츠 수.
```

## 참고 (블록 밖 — 사람용)

### 왜 이 규칙들인가 (과거 누락 원인)
- JS 내비(onclick) 미파싱 → 페이지 통째 누락 → ①에서 JS 문자열까지 파싱.
- 파라미터 라우트(`?type=…`, 필터/페이지네이션) 미발견 → 조합 전수 생성.
- 모바일 전용 자산(`_m` 등) → PC·모바일 2뷰포트.
- AJAX 탭이 마지막 상태만 남김 → 탭 전환마다 텍스트 저장.
- `alt` 등 속성 카피를 innerText가 못 잡음 → 속성 텍스트 별도 수집.
- 다운로드 중 폴더 삭제로 ENOENT → 쓰기 직전 폴더 보장.
- 카피가 이미지에 박힘 → ④ 이미지 OCR.
- 언론보도 상세(`pr_view.php` 등)가 외부 언론사 기사를 임베드 → 네트워크 image/* 무차별 수집으로 **언론사 사진·광고(다이어트 클릭베이트 등) 수백 장이 images/에 오염** → ③ **이미지/영상은 동일 출처만 다운로드**(외부는 URL만 기록). 문서 PDF는 예외로 외부도 받음.
- 같은 기사 미러 페이지의 **임베드된 외부 기사 상대링크**(`/news/articleList.html?sc_section_code=…` 등 언론사 CMS 경로)가 대상 origin 내부 라우트로 오인됨 → **크롤 트랩**(섹션코드 조합 무한 증식, 400페이지 한도까지 가짜 URL) → ① **기사 미러(게시판 상세) 페이지는 본문·이미지만 저장하고 그 안의 `<a>` 링크는 큐에 넣지 않는다**(상세는 leaf — 내부 내비는 이미 목록/홈에서 발견됨). + 외부 CMS 경로 패턴(`/news/article*`·`/bbs/` 등)은 전역 SKIP.
- 공식 문서 PDF가 다운로드 버튼(JS) 뒤 → content-type만 봐 0건 누락 → ③ 버튼/href 파싱 + 직접 fetch.
- 고밀도 표(가격·스펙·비교표)를 기본 해상도 1패스로 "요약"하고 넘어감 → ④ 크롭 재판독 의무화(요약 금지).
- SVG가 아웃라인(글자→패스, `<text>` 0개)이라 직접 파싱 0건 → ④에서 비전 OCR 대상으로 전환.
- 교차검증(Tesseract)을 "선택"이라 묵시적 생략 → ④ 실행/미실행을 report에 명시 의무화.

### 정확도·효율 개선
- **API 응답 캡처**(⓪·②): SPA는 텍스트가 XHR/fetch JSON으로 옴. 렌더 DOM 스크래핑보다 원본 응답이 정확하고, 탭 클릭 루프 의존을 줄여 더 빠르고 덜 깨짐.
- **리소스 차단**(⓪): 트래커/광고/분석/웹폰트 abort → 로드 시간↓(콘텐츠 자산은 차단 금지).
- **콘텐츠 해시 dedup**(⓪·③·④): 같은 페이지/이미지 다른 URL을 1건만 처리 → 저장·OCR 비용↓. 파일명=해시.
- **resume 체크포인트**(⓪): manifest에 해시·status 기록 → 재실행 시 완료분 skip, 부분 실패만 재시도.
- **모바일 조건부**(②): 분기 정황 있을 때만 2뷰포트 → 불필요한 2배 작업 제거.
- **OCR 문맥 grounding + 구조화 출력**(④): 페이지 텍스트·고유명사를 비전 LLM에 동봉 → 오탈자·환각↓. 자유서술 대신 JSON.
- **워커 풀 + 호스트 감속**(⓪): 동시 방문으로 처리량↑, 429/503 시 자동 감속으로 차단 회피.

### 새 대상 적용 시 교체 체크리스트
| 항목 | 값 |
|---|---|
| 대상 URL / 저장 경로 | `<TARGET_URL>` / `<SAVE_PATH>` |
| 도메인 컨텍스트 | `<DOMAIN_NOTE>` — 1b의 ⑤ fact 목록·출처를 이 성격에 맞게 정의 |
| 쿼리/파라미터 패턴 | 대상 사이트 실제 라우트 패턴(`?tab=`, `?category=`, `/page/2` 등) |
| 뷰포트 | 모바일 전용 분리 자산 없으면 PC 단일로 단순화 가능 |
| OCR 언어팩 | Tesseract 언어(kor/eng/jpn 등)를 대상 언어에 맞게 |

### 원천적 한계 (어떤 프롬프트로도 못 넘음)
- **완전 고아 페이지**: 링크·sitemap·UI 어디로도 도달 못 하는 라우트는 발견 불가.
- **cross-origin iframe 내부**(지도·결제·외부 위젯): 다른 도메인 임베드 내부는 수집 불가 — URL만 기록.
- **인증 영역**: 자격증명 없는 로그인/회원 전용 영역은 진입 불가 — URL만 기록.

### 사용법 (다음 현장에 붙여넣기)
1. 이 MD를 새 현장 프로젝트에 복사 → 위 **프롬프트 코드블록**만 AI에 전달.
2. `<TARGET_URL>`·`<SAVE_PATH>`·`<DOMAIN_NOTE>` 교체, "교체 체크리스트"대로 라우트 패턴·OCR 언어를 현장에 맞게 조정.
3. AI가 `[구현]`에 따라 추출기를 만들어 실행 → report.txt로 완료 조건 자가검증.
4. 추출 끝나면 **[1b단계](일-1b단계-검증보강.md)**로 넘어가 공식 1차 출처로 사실 대조·보강.
