# 블로그 발행 템플릿 (분양소식)

AI가 새 글을 쓸 때 **이 문서만 보고** `src/lib/news.ts`의 `POSTS` 배열 **맨 앞**에 객체 하나를 추가하면, `rss.xml` · `sitemap.xml` · `/news` 목록 · 글 페이지(`/news/[slug]`)에 자동 반영된다. (반영하려면 작성 후 `next build` → 재배포 필요.)

---

## 0. 발행 속도 (첫 배포 전 시드 vs 운영 주기)

- **첫 배포 전: 시드 글을 정확히 3편 작성해 첫 배포에 포함(3편 초과·미만 금지).** 새 사이트의 초기 콘텐츠라 "발행 속도"가 아니다(전부 첫 배포 t=0에 같이 게시) — 네이버가 양산으로 보지 않는다. 빈 `/news`로 띄우지 말 것(thin 회피·색인 시작).
- ⚠️ **시드 추가 전 `POSTS`를 비우고 시작.** 8단계는 샘플 0편(빈 `POSTS`)이 정상이지만, `POSTS`에 샘플·예시·더미 객체가 남아 있으면 **모두 제거**하고 실제 시드 3편만 남긴다 — 8단계 잔존 샘플 + 시드 = 4편+ **과발행**(예: 5편) 방지. 개수는 `[G10-SEED-COUNT]`가 자동 강제(첫 배포 = 전 글 동일 t=0 날짜일 때 **정확히 3편**, 운영 누적 시 자동 면제).
- **런칭 후 운영: 주 2편 이내로 꾸준히 누적.** 한꺼번에 대량 발행은 양산(어뷰징) 신호·색인 지연 → 시간에 걸쳐 분산. 목표 누적 30편+.
- 시드 3편은 **서로 다른 주력 키워드(카니발 0)** + 검증 fact로(§2.6·§2.5).

## 1. 필드 규칙 (어기면 빌드/RSS가 깨짐)

| 필드 | 형식 | 규칙 |
|---|---|---|
| `slug` | 영문 소문자 + 하이픈 | URL이 됨. **기존 글과 절대 중복 금지.** 예: `{단지영문}-{주제}-{연도}` |
| `category` | 한글 짧은 분류 | 예: `입지분석`, `단지소식`, `교통`, `생활권` |
| `title` | 한 줄 제목 | 25~40자 권장. 과장·미확정 단정 표현 금지 |
| `excerpt` | 1~2문장 요약 | RSS `description`·목록 카드 + og:description으로 그대로 노출. **80자 이내(엄수)** |
| `date` | `YYYY-MM-DD` | **형식 정확히.** RSS `pubDate`로 변환됨 (틀리면 피드 깨짐). 발행일 기준 |
| `lead` | 도입 문단 1개 | 단지 기본정보({주소}, 총 {세대수}, {평형}, {사업유형})를 자연스럽게 포함 |
| `sections` | 배열 | `{ h2: "소제목", paras: ["문단", "문단", ...] }` 를 3~5개 |
| `sourceNote` | 출처·면책 문구 | 아래 고정 문구 사용 권장 |

## 2. 콘텐츠 원칙 (필수 — 메모리/사이트 정책)

- **미확정 정보 창작 금지**: 분양가·입주일정·세대별 호수·정확한 일정 등은 입주자모집공고 전 단정하지 않는다. "입주자모집공고 시점 기준으로 안내" 식으로 처리.
- **보도 인용은 출처(언론사) 명시**: "~다는 분석도 제기되었습니다(파이낸셜뉴스 등 보도)." 형식.
- **사업유형 정확 표기**: "일반분양(분양)"으로 표기. 분양가·계약금은 입주자모집공고 기준으로만 표기하고, 미공고 수치를 단정하지 않는다.
- **GTX-C 등 예정 사업**: "(예정)" 표기하고 "관계기관 계획에 따라 변경될 수 있습니다" 단서를 둔다.
- 고정 식별자: 상담번호는 사이트 공통값을 따르며 본문에 임의 번호를 쓰지 않는다.

## 2.5. SEO·AI 유입 규칙 (블로그 글 한정)

> 기술 SEO(`<title>`·description·canonical·OG·Twitter·JSON-LD Article·H1/H2·breadcrumb·내부링크)는 `news/[slug]/page.tsx`가 글 데이터로 **자동 생성**한다. AI가 손댈 레버는 **`title`·`excerpt`·`category`·`h2`·문단 텍스트**뿐. 채널·키워드 전략 전반은 `일-9단계-SEO-GEO.md`를 따른다(여기선 글에 직접 적용되는 것만).
>
> ⚠️ 글 한 편으로 "최상단/1위"는 보장되지 않는다. 글의 역할은 **검색 의도 정합 + 화이트햇 품질**까지다. 순위는 사이트 전체 신호·오프페이지(네이버 블로그/카페·플레이스 등)가 함께 결정한다.

네이버·구글·다음·AI 4채널에 동시에 먹히게 쓰는 법:

- **키워드는 추측 말고 검색량 기반으로.** 네이버 검색광고 키워드도구·데이터랩·자동완성/연관검색어로 확인한 키워드만 쓴다(상세: `일-9단계-SEO-GEO.md` > [키워드 리서치]). 글당 **주력 키워드 1개 + 보조 2~3개**.
- **`title`**: 주력 키워드를 자연스러운 한 문장에 1회. 키워드 나열 금지. 과장·확정형("최저가·확정·직결") 금지.
- **`excerpt`**: 주력 키워드 + 핵심 fact(지역·세대수·분양 등)를 1~2문장. RSS·SERP 미리보기·OG에 그대로 노출되므로 가장 신경 쓸 것.
- **`h2`(소제목)**: 각 소제목에 보조 키워드(지역·교통·역명·생활권·입지 등)를 자연스럽게. 브랜드명(단지명)을 모든 h2에 반복 금지 — 스터핑 신호.
- **문단**: 한 문장 = 한 fact 단위(AI 인용 시 잘리지 않게). 질문형 검색에 답하는 자연어로(Q&A 친화) → 네이버 AI·AEO 인용에 유리.
- **검색량 큰 "분양가·청약"류 키워드(화이트햇)**: 사용자는 "{단지명} 분양가/청약"으로 검색한다. 분양가·청약 일정은 **입주자모집공고 기준 사실로만** 표기하고(미공고 시 "공고 후 안내"), 미확정 수치·일정 단정은 금지(표시광고법) (상세: `일-9단계-SEO-GEO.md` > [키워드 리서치]).
  - ⚠️ **청약 종료(선착순 단계)면 지난 청약 일정을 '안내·혜택'으로 내세우지 말 것**(미분양 인식·시점 오인). "청약 마감 · 선착순(잔여세대) 계약"으로 프레이밍하고, 키워드도 "선착순 분양 계약 방법" 류 해설형으로. [5단계 §콘텐츠 원칙](일-5단계-메인페이지.md)·[7단계 §분양 단계 전환](일-7단계-서브-분양-모델하우스.md) 준수.
- **AI 유입**: 위 자연어 fact + 출처 명시(보도 인용 시 언론사)·발행일(`date`)이 그대로 AI 인용 신호가 된다. 별도 작업 없음 — fact를 충실히 쓰면 자동으로 강해진다.
- ⚠️ **서브페이지 재진술 금지 (near-duplicate·키워드 카니발 방지 — 필수)**: 블로그 글은 `/location`·`/floorplan`·`/sales`·`/overview` 등 **서브페이지 fact를 같은 워딩으로 베끼면 안 된다**(thin·중복 콘텐츠 신호). 대신 **고유 앵글**로 쓴다 — 분양 절차/평형 선택 **가이드**, 지역·산업·개발 **시장 맥락 해설**, 비교·사례. **키워드도 서브와 분리**: 서브=단지·브랜드 주력 키워드(예: "{단지명} 평면도/분양가"), 블로그=해설형 롱테일(예: "국민평형 84㎡ 장점", "선착순 분양 계약 방법", "{지역} 반도체 직주근접"). **분양가·면적 등 상세 수치는 본문에 나열하지 말고 해당 서브페이지로 링크**(중복·카니발 회피). 글끼리도 같은 소재(예: 같은 공원/역) 반복 금지.

### 어뷰징(블랙햇) 절대 금지 — 검색엔진 페널티·표시광고법 위반

- 키워드 스터핑(같은 단어 부자연스럽게 반복), 숨김 텍스트, 도어웨이성 얇은 글
- 미확정 정보(분양가·입주 일정) 단정, 미공고 청약 일정·분양가 단정
- 출처 없는 시세 비교("주변 대비 N% 저렴"), 교통·학군 호재 "예정" 없이 단정
- 사실과 다른 내용을 검색 노출 목적으로 창작

## 2.6. 네이버 다양한 관련 검색어 노출 전략

> 글마다 **다른 검색어**를 노려 누적으로 검색어 커버를 넓힌다(자체 글=온페이지). VIEW·플레이스·네이버부동산 등 **오프페이지(사람 실행)는 `일-9단계-SEO-GEO.md` > [프롬프트 밖의 일]** 참조 — 여기서 반복하지 않는다.

- **1글 = 1주제(롱테일 다각화)**: 글마다 다른 검색어 — {지역}+분양/{사업유형}, {대표역}+신축·역세권, {지역}+직주근접/산업, {지역}+학군/생활권, {단지명}+평면도/모델하우스/분양가 등. 누적 30편+로 커버 확장.
- **연관검색어·자동완성 채굴**: 네이버 키워드도구·데이터랩·자동완성·연관검색어의 실제 쿼리·표기 변형을 `title`·`excerpt`·`h2`·본문에 자연 삽입(형태소 매칭).
- **글당 주력 1 + 보조 2~3, 카니발 금지**: 같은 주력 키워드로 여러 글 금지(자기잠식). 글끼리 키워드 분담.
- **질문형 자연어(Q&A) + 출처·발행일** → 네이버 AI 검색 인용에 유리.
- **주제 클러스터**: 관련 글끼리 내부링크 + 핵심 페이지(분양안내·관심고객등록) 연결.
- ⚠️ 검색어 늘리려 얇은 글 도배·복붙(near-dup)·스터핑 금지(§2.5 어뷰징과 동일).
