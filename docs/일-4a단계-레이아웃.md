## 1. 헤더 (`Header`, UI §3.1)

```
[{현장명}]   사업개요  입지환경  프리미엄  단지안내  평면도 …   [📞 {전화}] [관심고객등록]
```
- 홈(`/`): 처음 투명+흰 글자 → 스크롤 24px↑ 시 `bg-ivory/95 backdrop-blur`+`text-ink` 솔리드. 서브페이지는 항상 솔리드.
- 로고 `font-serif` bold, tracking-tight. **데스크탑 메뉴 = 한글 라벨 15px만**(`NAV[].label`, 번호 표기 없음). 영문(`NAV[].en`)은 모바일 보조. (9개 항목 폭 고려 `gap-5 xl:gap-6`)
- **우측 CTA 2개**(`lg:inline-flex`):
  - **전화**: `📞 + {전화}`(**아이콘 + 번호 노출** — 상담 전환 동선) — 1px 보더(`border-current`). `전화상담` 같은 **텍스트 라벨만 없이** 아이콘과 번호를 함께 표기(번호를 숨기지 말 것). `aria-hidden` 아이콘 + 링크 `aria-label="전화 상담 {전화}"`(번호는 시각·aria 양쪽). ⚠️ 아이콘만 두고 번호를 aria에만 넣지 말 것(콜바 줄과 일관 — 아이콘+번호).
  - **관심고객등록**: `bg-bronze text-ivory` **솔리드**, **`/modelhouse#reservation`**로 연결.
  - 두 버튼 모바일 숨김(`hidden lg:…`).
- **모바일**: 햄버거(SVG 라인 아이콘) → **전체화면 불투명 오버레이**(`bg-background`).
  - 상단: 단지명(`font-serif` bold) + 닫기(SVG ✕ 라인).
  - 메뉴: **구분선 리스트**(`flex-1 overflow-y-auto`, 각 항목 `border-b border-line py-4`, `items-baseline gap-4`) = 번호(브론즈 `font-accent` 15px italic, `01`~) + 한글 `font-serif` 24px + 영문 보조(`en`, 13px italic `tracking-[0.25em]` muted). ※번호는 **모바일 메뉴에만**(데스크탑 메뉴는 번호 없음). ※간격 리스트(gap)가 아니라 **구분선 행** 리스트.
  - 하단: **가로 2분할 CTA**(`flex`, 각 `flex-1 h-14`) — 좌 `관심고객 등록`(브론즈 → `/modelhouse#reservation`) | 우 `전화`(잉크, SVG 전화 아이콘 + `{전화}`, tel). ⚠️ 전화만 있는 통바 금지 — 관심고객등록을 함께(전환 동선).
- ⚠️ **모바일 오버레이는 `<header>` 밖(형제)에 렌더한다.** 헤더 솔리드 시 `backdrop-blur`(=`backdrop-filter`)가 걸리는데, **`backdrop-filter`/`filter`/`transform`은 자식 `position:fixed` 기준을 뷰포트가 아닌 그 요소로 바꾸는 containing block을 만든다.** 오버레이가 헤더 자식이면 `fixed inset-0`이 헤더 박스(~64px)에 갇혀 서브페이지·스크롤 시 메뉴가 안 보인다. → `return (<>{<header/>}{open && <오버레이 fixed inset-0 z-[60]/>}</>)`. (홈 최상단은 `bg-transparent`라 blur 없어 버그 안 보임 → "서브에서만 안 됨" 오인 주의.)
- **하단 고정 `MobileCallBar`**(모바일, `body`에 `pb-[56px]`): **2분할 — 좌 `관심고객 등록`(브론즈 → `/modelhouse#reservation`) + 우 `📞 + {전화}`(잉크, tel)**. 아이콘+번호(라벨 없음), `aria-label="전화 상담 {전화}"`. 데스크탑 `lg:hidden`.
- **중복 제거**: 콜바에 관심고객등록이 있으므로 **모바일에선 히어로 원형 CTA 숨김**(`hidden lg:block`).
> 개선(50대 UX): 데스크탑 메뉴·CTA 터치 영역 48px+, 메뉴 자간 한글 0.02em 이하.

## 1.6 레이아웃 메타데이터 (`RootLayout` title — ⚠️ 브랜드명 중복 금지)

- `layout.tsx`의 `metadata.title`은 **`{ default: "{현장명} | {메인 의도키워드}", template: "%s | {현장명}" }`**. `template`은 자식 페이지 title 뒤에 `| {현장명}`을 **자동으로 1회** 붙인다.
- ⚠️ **그래서 서브/메인 페이지는 title을 `title.absolute`로 전체값을 박아 template을 우회한다.** 페이지 title을 일반 문자열(`title: "..."`)로 주면 template이 브랜드명을 **한 번 더** 붙여 `{현장명} … | {현장명}`처럼 **브랜드 2번** 중복된다(이 현장에서 실제 발생→수정한 버그).
  - 서브/메인: `title: { absolute: "{현장명} {섹션} | {의도키워드}" }` (브랜드 앞 + 의도키워드 꼬리 — 9단계 [HTML title 절대 불변] §구현 가드).
  - `news/[slug]`: template 활용 → `title: post.title` (글제목만, template이 `| {현장명}` 접미). **이 라우트에만 template 사용.**
  - 홈: `title.default`에 전체값. `privacy` 등 단순 페이지는 `title: "개인정보처리방침"`(섹션명만)로 template 접미 허용.
- 검증: 빌드 후 각 라우트 `<title>`에 `{현장명}`이 **정확히 1회**인지 확인(2회면 absolute 누락).

## 3. 서브페이지 히어로 (`PageHero` — 페이지별 일러스트 장면, 실사 미사용)

> 서브 히어로는 **실사 안 씀**(메인=실사와 대비). `PageHero{title, eyebrow, motif}` = 색면 + **페이지별 벡터 일러스트 장면**(코드로 작도, 이미지 자산 아님 → `next/image` 불필요). ⚠️ 텍스트 워터마크(거대 글자) 폐기.

| 요소 | 구현 |
|---|---|
| 배경 색면 | `bg-background`(#fafaf8) · `border-b border-line` |
| 텍스트 페이드 | 좌측 `bg-gradient-to-r from-background … to-transparent` — 모티프가 좌측 텍스트를 안 가리게 |
| eyebrow | 브론즈 1px hairline(`h-px w-8`) + `font-accent` italic `tracking-[0.3em] text-bronze` 15~18px |
| H1 | **브랜드명을 H1에 포함** — `<span class="block text-[15px] text-muted">{현장명}</span>` + 큰 제목(`font-serif` 38px → `sm:text-7xl`). H1 = `{현장명} {페이지명}`. ⚠️ **두 block `<span>` 사이에 명시 공백(`{' '}`)** — 없으면 `textContent`가 "{현장명}{페이지명}"으로 붙어 키워드 토큰 깨짐(9단계 §검증). 시각은 block이라 그대로 두 줄. |
| breadcrumb | `홈 / {현재 페이지}` — `text-muted` 13px `tracking-[0.2em]`, `/`는 브론즈 |

**일러스트 장면 (`motif` — 페이지별 테마)**
- 테마: `circle`(사업개요=건축 스카이라인·크레인)·`map`(입지=도시맵·도로·전철·핀·나침반)·`bloom`(프리미엄=정원·꽃·나비·새)·`plan`(단지=배치도·나무·연못·벤치)·`unit`(타입=평면+가구)·`doc`(분양=문서·표·차트)·`gallery`(모델하우스=거실 인테리어)·`news`(소식=기사 카드·말풍선)·`qa`(FAQ=말풍선·물음표·사람).
- **멀티요소 + 깊이 3레이어**: 배경(능선·구름 등 opacity ~0.1) → 중경(구조 ~0.22) → 전경(디테일 ~0.4). 흩어진 도형 1개가 아니라 **한 장면**으로. 공통 브론즈 헤어라인 + 옅은 fill로 조화. `aria-hidden`·`pointer-events-none`.

**잘림 0 · 사이즈별 분리 (핵심 규칙)**
- **`preserveAspectRatio="xMidYMid meet"`**(잘림 0). **`slice` 금지**(자름).
- **사이즈별 따로 디자인**: **PC·태블릿 = 가로 파노라마**(넓은 viewBox, 우측 컨테이너 `lg:w-[62%]`) / **모바일 = 정사각 미니장면**(viewBox 1:1, 우측 `w-[46%]` 세로 중앙, 박스 꽉 채움 → 상하 여백 최소).
- **가장자리 여백**: 중앙 `max-w-[1280px]` 컨테이너 안에 배치 + `right/top/bottom` 여백 → 화면 끝에 안 닿음(잘려 보임 방지).
- **문구 안 가림**: 텍스트=좌측 / 모티프=우측 + 좌측 페이드. 글자는 `#fafaf8` 위 `text-ink`(≈13:1).

> 여백: `max-w-[1280px] px-6 pb-16 pt-28 sm:px-10 sm:pb-20 sm:pt-32`. 장면의 실제 SVG 좌표는 코드(`PageHero.tsx`)에 두고, 이 문서엔 원칙만(범용).

## 4. 서브페이지 공통 구조 (UI §2.0)

- 모든 서브: `히어로 → 짧은 인트로(1~2문장, `bg-surface` `max-w-[920px] px-6 pt-16 sm:px-10 sm:pt-20`) → 섹션 01…`. 인트로 = AI 인용 1차 후보 + 오리엔테이션.

## 5. 전환·운영 원칙 (IA)

1. 관심고객등록 별도 페이지 X → 메인 하단 섹션 + `/modelhouse#reservation`. 모든 버튼 모델하우스 폼으로 일원화(`id="reservation"`는 모델하우스 **우측 예약 폼 자체**에 부여 + `scroll-mt-24` — 모바일 2단 세로 스택에서 좌측 정보가 아니라 **폼 입력부로 직행**. 2단 래퍼/좌측 컬럼에 id 금지).
