## 4. 컬러 팔레트 (UI §1.1)

| 역할 | 토큰 | 값 | Tailwind 클래스 | 사용 |
|---|---|---|---|---|
| Background (Base) | `--background` | `#fafaf8` (웜 오프화이트) | `bg-background` = `bg-ivory` | 페이지 바탕·교차 섹션·서브 히어로 |
| Surface (섹션) | `--surface` | `#ffffff` (순백) | `bg-surface` | 본문 콘텐츠 섹션 |
| Ink (Foreground) | `--foreground` | `#1a1815` (오프블랙) | `text-ink` = `text-foreground` · `bg-ink` | 본문·헤드 20%, 반전 다크 섹션 |
| Muted text | `--muted-text` | `#6e665a` (대비 ≥ 4.5:1) | `text-muted` | 읽는 보조 텍스트·라벨·캡션 |
| Line | `--line` | `#d6cfc2` | `border-line` | 디바이더·hairline |
| Bronze (Accent) | `--bronze` | `#8c7b5e` | `text-bronze` · `bg-bronze` | 액센트 1~2% |

**원칙**
- 채도색은 브론즈만(hairline·이태릭 영문에만). 다크모드 미지원.
- 바탕 `#fafaf8` + 섹션 `#ffffff` 2단 위계 — 두 톤 미세 대비로 섹션 위계.
- 읽는 보조 텍스트는 `text-muted`(#6e665a, ≥4.5:1)까지만. 더 연한 회색은 디바이더·비핵심 메타에만.
- 브론즈 텍스트는 장식 영문(큰 글자)에 한정 — 14px 미만 본문·핵심 정보엔 금지.
> 별칭: `bg-ivory`=`--background`, `text-ink`=`--foreground`. 보조 텍스트 토큰은 `--muted-text` 하나뿐(더 연한 보조색 신설 금지).

1. `globals.css` `:root` 값 현장 톤 확인(보통 그대로) + 폰트 로딩 확인
2. `src/lib/content.ts`의 `PROJECT`/`NAV`/섹션 블록·사업개요(`LineSpec`) 값을 현장값으로 교체 — **UI 컴포넌트는 거의 그대로 재사용**. 단지 고유 fact는 `src/lib/site.ts`+`content.ts` 단일 소스화.
3. `Header`/`Footer`(다크)/`PageHero`/`MobileCallBar` 브랜드 텍스트 확인 → **4a단계**(레이아웃)·**4b단계**(공통 컴포넌트)
4. `/` 메인(`HomeHero`·`MagBlock`·분양소식/FAQ·관심고객등록·ABOUT) → **5단계**
5. `/overview`→`/location`→`/floorplan` 순 → **6단계**
6. 폼(관심고객·예약) → 3단계 규정
7. **이미지·영상 자산 물질화 (2단계 책임 — 빠지기 쉬움)** — 경계를 명확히 한다:
   - **[2단계] 이미지 물질화**: `public/images/<섹션>/` 디렉토리 생성 + **[1c](일-1c단계-이미지큐레이션.md)의 `curated/<category>/`를 정본**으로 **webp 변환해 복사**(category=섹션: hero·overview·location·premium·complex·type·sales·modelhouse·common). 시각 분석은 1c 결과(`curation.json`) 재사용 — **2단계에서 재분석 금지**.
   - **[2단계] 영상 물질화**: 1c의 `curated/video/`(keep 영상)를 정본으로 `public/videos/`에 배치한다. ① 용량 최적화(웹용 H.264/mp4 재인코딩, 필요시 webm 추가), ② **포스터 프레임**(`curated/`의 poster 또는 첫 프레임)을 `public/images/video/`에 webp로 둔다(LCP·지연로드용), ③ 5~8단계에서 `<video poster>` + lazy load로 삽입. **1c에서 `maybe`로 분류된 영상(예: 출처·오인 이슈)은 사람 확인 전까지 물질화 보류** — `curation.json`의 판정 그대로 따르고 임의 keep 금지.
   - **[5~8단계] 삽입**: 그 파일을 JSX 섹션에 이미지는 `<Image/>`, 영상은 `<video poster>`로 꽂는다(`curation.json`의 `category`→라우트 매핑대로).
   - ⚠️ **물질화(2단계)와 삽입(5~8)을 혼동해 둘 다 건너뛰지 말 것.** 2단계가 `public/images/`·`public/videos/`를 안 만들면 5~8단계가 꽂을 파일이 없다.
   - OG 이미지: `public/images/og/{현장영문}-og.jpg`(1200×630, 영문-하이픈). ⚠️ **OG는 webp 금지 — `.jpg`(또는 `.png`)로 생성**한다. 카카오톡·네이버·페이스북 등 SNS OG 크롤러가 webp를 미리보기로 렌더하지 못해 썸네일이 깨진다(본문 콘텐츠 이미지만 webp, OG는 jpg/png).

## 완료조건 (기계 판정)

> 형식 `[Gxx-KEY] 설명 | auto|manual`. 마스터 `scripts/verify.mjs`가 이 `[Gxx-*]`를 파싱해 **구현·PASS를 강제**(이 문서에 ID를 선언했는데 스크립트에 검사가 없으면 = RED / 검사는 있는데 어느 md도 선언 안 하면 = 경고). **전부 GREEN 전엔 이 단계 "완료" 금지.**

- [G2-ROUTES] 9 라우트 스캐폴드(overview·location·premium·complex·floorplan·sales·modelhouse·news·faq) | auto
- [G2-TOKENS] globals.css 디자인 토큰(--bronze·--ink 등) 정의 | auto
- [G2-OGIMG] OG 이미지 jpg/png 실존(webp 금지) | auto
- [G2-PLACEHOLDER-SRC] content.ts·site.ts에 `{현장명}`류 미치환 placeholder 0 | auto
