- [ ] Tailwind v4 설치 확인(globals.css가 `@import "tailwindcss"` 전제) — `npm ls tailwindcss prettier prettier-plugin-tailwindcss`로 버전 확인

## 참고 (블록 밖 — 사람용)

- **이 단계는 "빈 프로젝트"까지만**이다. 정보 추출·디자인·페이지는 1단계부터.
- **Tailwind는 반드시 v4** — 2단계 `globals.css`가 v4 문법(`@import "tailwindcss";`·`@theme inline`) 기준이라 v3로 깔면 토큰 설정이 안 맞는다.
- **현장명-영문**만 그 현장에 맞게 바꾸면 다른 일반분양 현장에도 그대로 재사용 가능.
- 분양광고 게재 금지 표현·수치 규정은 콘텐츠 단계(3단계 전역규칙·5~8단계)에서 다룬다. 세팅 단계에선 신경 쓰지 않는다.
