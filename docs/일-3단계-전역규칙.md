## A. 50대 가독성 — 최우선 원칙 (UI §0, 모든 규칙에 우선)

1. **읽어야 하는 글자는 작게/가늘게/연하게 두지 않는다.** 본문 ≥ **17px**, weight **≥400**, 행간 **1.75**. 베이스는 Noto Sans KR을 **400/500/700/900만** 로드(Light 200~300 미로드).
2. **핵심 정보(가격·면적·일정·주소·전화·예약)는 `text-ink`(#1a1815)·17px+·weight 500.** 연한 회색·브론즈·초소형 영문 라벨로 핵심 정보 표기 금지.
3. **넓은 자간은 "장식 영문"에만.** 한글 본문·핵심 숫자에 자간 벌리지 않음.
4. **기능 텍스트는 한글 우선.** 메뉴·버튼·에러·안내는 한글 주, 영문은 보조·장식.
5. **대비는 본문 7:1, 보조 4.5:1 이상.** `text-muted`(#6e665a)보다 연한 회색을 읽는 글자에 쓰지 않음.
> 톤 다운된 갤러리 느낌은 이미지·여백·라인·구도가 만든다. 텍스트는 그 안에서 또렷해도 고급스러움이 안 깨진다.

## B. 모션 (UI §4)

| 항목 | 값 |
|---|---|
| Easing | ease-out 계열 고정 |
| Duration | 0.3 ~ 0.9s |
| Hover | opacity-60 또는 scale 1.01~1.02 / translateY -2~4px |
| Bounce/Spring | **사용 금지** |
| Parallax | 이미지에만 약하게 |

- 진입 모션: opacity 0→1 + translateY 20→0, **한 번만(`once`)**.
- 텍스트는 진입 후 **완전 정지**(읽는 중 움직임 금지). 자동 슬라이드는 6초 이상 또는 수동 우선.
- **`prefers-reduced-motion: reduce` → 모든 애니메이션/트랜지션 0.01ms 무력화**(globals.css 전역, 신규 모션도 깨지 말 것).
- **영상 자산 — 전역 규칙(메인·서브 어디든 `<video>` 쓰면)**: 로딩 최적화 의무.
  - **압축**: 배경/장식 영상은 오버레이 아래라 과한 해상도 불필요 → **1280폭 다운스케일 + libx264 `crf ~26`** · **`-an`**(오디오 제거) · **`+faststart`**(웹 스트리밍). 용량 목표 **≤1MB**(가능하면 수백 KB).
  - **`preload="metadata"`**(또는 `none`) — 영상이 **LCP를 막지 않게**. 첫 페인트는 **경량 poster(webp)** 가 담당.
  - 자동재생은 `muted playsinline loop`, **`prefers-reduced-motion`·iOS 저전력(자동재생 차단) 시 poster 정지컷 폴백**.
  - 측정 기준(LCP/CWV)=**9단계**, 배포 직전 통과 게이트=**11단계**.

## C. 톤 & 보이스 (UI §5)

- 느낌표 금지 · 헤드라인 마침표 생략 · 형용사 최소화(숫자·브랜드·재료가 말하게).
- 영문 키 카피 병기 가능 — **영문은 장식, 핵심 안내는 한글로도 반드시 제공.**

| ❌ 금지 | ✅ 권장 |
|---|---|
| "최고급 프리미엄 단지!" | "가장 정제된 거주" |
| "도보 N분 초역세권" | "도보 N분 · {인근역}" |
| "{지역} 핵심 입지" | "{정확한 지번 주소}" |
| "특별한 라이프스타일 제공" | "지하 N층, 커뮤니티 약 N평" |

**금지 표현(게재 위험)** — 현장별 `사이트콘텐츠.md` 게재 금지 표현 준수. 공통: "즉시 전매 가능"/"토허제 100% 제외"/"주택 수 미포함"류 단정, 실제와 다른 수치 과장(현장 확정값과 1:1 일치).

## D. 반응형 (UI §6)

| Breakpoint | 너비 | 변화 |
|---|---|---|
| Mobile | ~639px | 단일 칼럼, `px-6`, 헤드 38px, 본문 17px, 하단 `MobileCallBar` |
| sm | 640px+ | 2칼럼 시작, `px-10`, 헤드 확대 |
| Desktop | 1024px+ | 풀 그리드, 데스크탑 메뉴(`lg:flex`) |
| Wide | 1280px+ | `max-w-[1280px]` 유지 |

- Hero 영상 → 정지 이미지 폴백. **Hero 높이 = `min-h-[calc(100svh_-_56px)]`**(콜바 뒤로 안 들어가게, 데스크탑 `lg:h-screen`).
- 와이드 이미지 모바일 중앙만 보임 → `object-position` 조정/모바일 크롭.
- **헤드만 축소, 본문 17px 유지.** 햄버거 → 전체화면 불투명 오버레이. sticky 인덱스는 상단 가로 chips(15px+).

## E. 접근성 (UI §7 — 50대 가독성 KPI)

- 본문 대비 7:1 이상(`#1a1815` on `#fafaf8`≈13:1 / on `#ffffff`≈14:1).
- 본문 최소 17px·weight 400+(Light 미로드). 읽는 보조는 `text-muted`(≥4.5:1)까지만.
- 핵심 정보(가격·면적·일정·주소·전화) 17px+ `text-ink` 500. 브론즈 텍스트 14px 미만 금지.
- **정보 구분은 색만으로 하지 않는다** — 굵기·언더라인·아이콘 병행.
- 인터랙티브 요소 키보드 포커스(브론즈+outline). 터치/클릭 영역 44×44px(버튼·메뉴 48px 지향).
- 기능 텍스트 한글 우선. `prefers-reduced-motion` 대응, 읽는 중 텍스트 정지.

## F. 콘텐츠 작성 규칙 (IA — META·H2·H3·콘텐츠)

- **META DESCRIPTION**: 페이지별 **≤80자**(네이버 SERP 잘림 방지), 핵심 키워드 포함, title과 동일 키워드 단순 반복 금지(fact 보강).
- **H2**: 검색 의도 충족 **독립적 정보 섹션**(키워드 나열 금지). fact·지역·주제 키워드 자연 삽입하되 **브랜드명을 모든 H2에 반복 금지**(브랜드는 H1·title·ABOUT·본문이 받침).
- **H3**: 섹션 내 세부 정보 그룹화에 적극 활용(예: 커뮤니티 → 다이닝/액티비티/라운지).
- **콘텐츠**: 정보성 중심, 광고 문구 나열·과장 수식어 금지. 핵심은 표·목록·요약. 객관적 근거 기반. 미확정은 "입주자모집공고 기준 추후 안내". 동일 내용 반복 회피(페이지 간·내).
- **콘텐츠 충실화 표준(분량·구조 — 5~8단계 정본)**: 각 페이지 = **리드 문단(AI 인용 1차 후보)** + **검색의도형 H2/H3**(실제 검색어 자연 삽입) + **fact 표·목록** + **내부링크 순환** + **About 블록**. **최소 분량은 각 단계(5~8) 완료조건에 명시**(예: 홈 ABOUT·서브 About 800~2,000자). 분량은 **정보 밀도로 자연 충족** — 채우기용 글·키워드 도배·near-duplicate(페이지 간 복붙)·은닉 텍스트는 **어뷰징(금지)**. 네이버/구글/다음/AI 공통: 페이지마다 **고유 의도·고유 텍스트**, 깊은 본문은 서브로 분산.
- **FAQ는 `/faq`로 일원화** — **FAQPage JSON-LD 스키마는 `/faq`에만**(서브페이지·메인 복제 금지 = 스키마 중복 방지). 메인은 **대표 N개 질문+간단답 미리보기 허용**(단 FAQPage 스키마는 넣지 않음, /faq 전체 보기 링크 동반).
- **서브페이지 공통 구조**: `히어로 → 짧은 인트로(1~2문장) → 섹션`. 상단 리드 문단 = **AI 인용 1차 후보**. (모델하우스는 2단 좌측 소개가 인트로 — 예외)
